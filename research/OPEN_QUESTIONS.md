# Open questions and useful next experiments

These are research directions, not implemented features or promised capacities.

| Question | What is known | Useful discriminating work |
|---|---|---|
| Arbitrary ordered CPU partner changes | A health-triggered switch can skip a live teammate; target ordinal is a separate CPU state | Trace target selection while keeping roster, items and preceding actions controlled; no verified MMD order override exists |
| Special spawned team group formats | Ordinary tag-0 candidate rosters work; 21 original Galaxy donors contain unsupported special layouts | Decode tag-FFFFFFFF consumers and serialization before allowing transfer |
| Full D-pad neighbor priority | A connected Frieza node became accessible after relocation; diagonals exist in stock maps | Vary angle/distance with a fixed graph and log native selection; do not ban all diagonals |
| Battle Zone stored +30 expression | Copied to selected-stage snapshot; not evaluated by traced stock secret selection | Trace every remaining consumer or establish a controlled field-only effect before labeling unused |
| Zone callbacks 2/3 | MAIN meanings are known; context callbacks differ | Identify Zone-installed callbacks; do not reuse MAIN labels without proof |
| All handicap/Seal interactions | Labels/dispatch/catalogs and mission bitmap targeting are known | Play targeted A/B controls for each effect and Seal interaction |
| Arena overrides in Battle Zone | +1C read and conversion are traced; original arenas vary | Complete a field-only arena gameplay control; earlier automation did not reach battle |
| Extra independent Galaxies | Existing-icon transfer works; a 67th aggregate aliases globals | Coordinate owner lookup, unlock state, world objects, aggregates and every save/UI consumer |
| Extra standalone Zones | Loader and menu use eight slots per mode | Expand menu, positional loading, save routing and run-state consumers together |
| Larger Tutorial roster | Sparse root 63 persisted in D2; full 64-visible fixture exhausted circles | Rework per-kind pools, then test return paths, save, new game and cold reload |
| Battle Zone expansion | Enlarged-bank fixtures failed; cell53 also exceeds visual grid | Start with original first node and valid Stamp lists; isolate within-grid branch additions before extrapolating capacity |
| Engine roster and item expansion | Studio can label a modded catalog; native arrays remain separate | Audit the mod's executable, sentinel/native count and item loops rather than suppressing warnings |
| Fusion completeness | Slots and links are editable | Verify eligibility, partner selection, native animation and every destination combination independently |
| Physical PS3 and cross-region EBOOT patches | Editor data compatibility user-confirmed; exact code work European/RPCS3 | Separate hardware/region controls; never reuse recorded ELF addresses blindly |

No result here establishes the mathematical maximum of a rewritten engine. Further
work should use one-variable controls, preserve originals, record exact hashes,
inspect neighboring RAM/save fields and require native persistence before advertising
additional independent progress capacity.
